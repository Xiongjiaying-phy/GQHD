# Before uploading

- This is a publication-preparation snapshot, not a claim of full end-to-end validated reproducibility.
- Confirm code authorship and ownership for the original and dependency modules, then choose a license. No license is granted by this assembly.
- Supply author names, paper title, DOI/arXiv and repository URL before adding `CITATION.cff`; none are fabricated here.
- Resolve BPS provenance and distribution permission. External GW samples must match the recorded hash; check source terms.
- Review redistribution of digitized HIC vertices and observational regions in saved figures.
- Review manuscript language against `Methods.md`; in particular original anchor versus local seed, soft penalties versus acceptance, and finite-grid stability.
- Re-run the full objective and tidal preflight in a clean environment once external inputs are available. The bundled preflight is historical only.
- Saved curves can be replotted, but this bundle does not reconstruct public observational contours from their raw samples.
- No server launch credentials, remote job scripts or raw observational samples are intentionally included.

## Version selection

The objective is the frozen September 8 snapshot saved in Loss.zip, not later current-workspace optimizer edits. GQHD1–4 final numerical values are from the corresponding seven-model delivery. Packaging does not claim optimization globality and does not alter published results.
